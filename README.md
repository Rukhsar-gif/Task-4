# Digital Clock

A responsive digital clock created as **Task 4** of my
**Web Development Internship at Veda Technology**.

## 📌 Project Overview

This project is a simple browser-based digital clock that displays
the current hours, minutes, and seconds and automatically updates
every second.

The project demonstrates the use of JavaScript Date objects,
timers, DOM selection, DOM updates, and number formatting.

## 🎯 Objective

The objective of this task was to practice:

- JavaScript Date objects
- `setInterval()`
- DOM selection
- DOM updates
- String formatting
- Leading zero formatting
- Basic responsive CSS

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Live digital clock
- Displays current hours, minutes, and seconds
- Automatic update every second
- Current date display
- HH:MM:SS format
- Leading zeros for single-digit values
- Responsive design
- Device-based local time
- Clean and simple user interface
